# 🎹 Piano-Virtual

Piano virtual feito com **HTML, CSS e JavaScript**, para tocar notas pelo mouse, tela sensível ao toque ou teclado do computador.

## ✨ Funcionalidades

- Tocar notas ao clicar nas teclas do piano.
- Tocar pelo teclado do computador.
- Ajustar o volume.
- Mostrar ou ocultar as letras das teclas.
- Interface responsiva para celular e computador.
- Controles acessíveis por teclado.

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript (Vanilla)
- Git e GitHub

## 🚀 Como executar

1. Baixe ou clone este repositório.
2. Abra a pasta no VS Code.
3. Abra `index.html` no navegador ou use a extensão **Live Server**.

Os caminhos dos arquivos de áudio são relativos à raiz do projeto. Mantenha a pasta `assets` junto de `index.html`.

## 🎼 Como tocar

Use as teclas indicadas no piano:

`A W S E D F T G Y H U J K O L P`

Também é possível clicar nas teclas com o mouse ou tocar em uma tela sensível ao toque.
